ISTRUZIONI:
1. Apri la repository GitHub e la sottocartella indicata nel percorso (es. Sources/SculptShowApp).
2. Con Add file > Upload files trascina i file corrispondenti, sostituendo gli esistenti.
3. Conferma Commit changes su main. Ripeti per le altre cartelle.
4. Carica TUTTI i file prima di considerare definitivo il risultato della build.
5. Apri GitHub > Actions > ultima build verde > Artifacts > Sculpt-Show-macOS.
6. Estrai il pacchetto due volte per arrivare a Sculpt Show.app.

NOTA: non serve modificare .github/workflows/macos-build.yml.
NOTA: non eliminare manualmente gli altri file.
NOTA: non caricare solo README o .plist: la nuova funzionalità richiede tutti i file sorgenti indicati.
