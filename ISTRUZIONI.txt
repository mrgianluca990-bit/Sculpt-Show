PER L'AGGIORNAMENTO
1. Estrai Sculpt-Show-v0.14.1-LTC-Hold-Trim-Delete-Update.zip.
2. Su GitHub, apri il repository e fai Add file > Upload files.
3. Carica i file estratti nelle rispettive posizioni (Sources, Tests, Scripts, README, ISTRUZIONI).
4. Fai commit sul branch main; attendi il risultato di GitHub Actions.
5. Scarica l'app macOS dall'artifact Sculpt-Show-macOS del run riuscito.

NON caricare lo ZIP come singolo file nel repository: GitHub deve ricevere i sorgenti nei loro percorsi.
Non sovrascrivere con un vecchio pacchetto 0.14.0 dopo questo aggiornamento.

VERIFICHE RICHIESTE SUL MAC
A. Cue con LTC attivo: PAUSE => il reader GENERATED mostra HOLD + ultimo TC, STOP lo cancella; RESUME riparte dalla posizione in pausa.
B. TC OFFSET: prova +00:00:01:00, poi -00:00:00:10 e verifica TC GENERATED/IN.
C. LTC LEVEL TRIM: regola -12 dB / 0 dB durante il GO e verifica il livello sul canale LTC in Core Audio.
D. Seleziona una cue e premi Delete/Backspace; prova anche un campo di testo nell'Inspector per assicurarti che Backspace continui a cancellare i caratteri, NON la cue.

NOTA LTC: in pausa il segnale audio LTC diventa silenzioso; non si emette un frame fermo continuo (potrebbe ingannare i dispositivi chase esterni). Il display GENERATED mantiene invece il valore e mostra HOLD.

Test locali: 119 superati (Linux), parse Swift verificato. Build vera macOS da verificare su GitHub.
