SCULPT SHOW 0.11.0 - CONVERGENZA CUE / BUILD CUMULATIVA
======================================================

Base pubblicata verificata su GitHub: Sculpt Show 0.10.4.
La versione 0.10.5 è inclusa nel pacchetto, anche se non è stata
ancora caricata nel repository.

METODO CONSIGLIATO (GitHub via browser):
1) Scarica Sculpt-Show-v0.11.0-Cue-Convergence-Update.zip
2) Estrai lo ZIP.
3) Apri https://github.com/mrgianluca990-bit/Sculpt-Show
4) Carica i file nelle corrispondenti cartelle, preservando la struttura.
   ATTENZIONE: non caricare l'intera cartella principale come sottocartella
   di main. Le directory sono Sources, Tests, Scripts.
5) Commit su main: GitHub Actions avvierà la build macOS universale.
6) Scarica l'app da Actions -> ultimo run -> Sculpt-Show-macOS.

ALTERNATIVA: usa Sculpt-Show-v0.11.0-Complete-Source.zip per
sostituire tutti i sorgenti. Include script, workflow, test, icona.

NON rimuovere gli script esistenti e NON cancellare .scshow.

IL PACCHETTO È SORGENTE: finché GitHub Actions non restituisce
SUCCESS, non considerarlo un'app compilata né una versione live stabile.
