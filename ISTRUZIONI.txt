SCULPT SHOW 0.10.1 — INSTALLAZIONE ICONA MACOS
================================================

Questa patch cambia SOLTANTO il packaging dell'app: nessun file Swift
modificato e nessuna modifica a routing, cue, Rules, MIDI o marker.

CARICA SU GITHUB 3 FILE NELLA CARTELLA "Scripts":
https://github.com/mrgianluca990-bit/Sculpt-Show/tree/main/Scripts

   1) Scripts/SculptShow.icns     (NUOVO file, icona per Dock/Finder)
   2) Scripts/Info.plist         (SOSTITUISCE la versione 0.10)
   3) Scripts/build-macos.sh     (SOSTITUISCE la versione 0.10)

Passaggi:
  - Estrai questo ZIP.
  - Apri su GitHub la cartella Scripts (link sopra).
  - Scegli Add file > Upload files.
  - Trascina SOLTANTO i tre file contenuti nella cartella Scripts
    dello ZIP (non caricare la cartella Scripts dentro Scripts).
  - Conferma il commit. GitHub Actions avvia la compilazione.
  - Scarica l'artifact Sculpt-Show-macOS dalla nuova build:
    https://github.com/mrgianluca990-bit/Sculpt-Show/actions
  - Sostituisci l'app in Applicazioni con la nuova build.

NOTA: SculptShow-icon-preview.png e una anteprima opzionale; NON va caricata.

L'icona e inclusa nel bundle "Sculpt Show.app/Contents/Resources/SculptShow.icns"
e dichiarata in Contents/Info.plist (CFBundleIconFile).
Se il Dock visualizza ancora la vecchia icona, rimuovi e riaggiungi
Sculpt Show dal Dock (macOS puo usare una cache delle icone).

VERSIONE: 0.10.1 (sola integrazione icona)
